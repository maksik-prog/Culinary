Задание: Графовая база данных — Кулинария
(Рецепты, ингредиенты, техники приготовления, заменяемость продуктов)

В соответствии с вариантом задания выполнить следующие действия:

1. Создайте не менее трёх таблиц узлов.
   Например, одноклассники, сокурсники (одногруппники), учебные дисциплины,
   книги (жанры книг), фильмы (жанры книг), города.

2. Создайте не менее трёх таблиц рёбер.
   Например, дружит, проживает, списывает домашнее задание, рекомендует книгу
   или фильм (жанр). Учитывайте, что графы в SQL Server — направленные.
   Например, связь "Дружит" обычно двусторонняя, а связь "Платит" — односторонняя.
   Для таблиц узлов использовать CONNECTION CONSTRAINT, чтобы ограничить узлы,
   которые может связывать ребро. Таблицы рёбер должны содержать атрибуты самого
   ребра (например, дата_события, вес_связи или статус).

3. Заполните для каждой таблицы узлов не менее 10 строк.

4. Введите данные в таблицы рёбер для установления нужной связи между узлами.

5. Используя функцию MATCH, напишите не менее 5 различных запросов к построенной
   графовой базе данных. Использовать цепочку из 3-х и более узлов
   (например: "Найти все фильмы, в которых снимались актеры, работавшие с
   режиссером X").

6. Используя функцию SHORTEST_PATH, напишите не менее 2 различных запросов к
   построенной графовой базе данных (используйте как шаблон "+", так и "{1,n}"),
   например, "Найти кратчайший путь длиной от 1 до 5 шагов с выводом имен всех
   промежуточных узлов". Требуется использовать функции LAST_NODE и STRING_AGG
   для отображения пройденного пути.

7. Нарисуйте в https://www.diagrams.net/ диаграммы для пунктов 3-4
   (см. видео "Графовые базы в MS SQL Server" https://youtu.be/LyXaerp6tRQ).
   Все диаграммы выполнить в одном файле .drawio, каждую на отдельной странице.

8. Визуализируйте граф в Power BI с помощью Force-Directed Graph
   (см. видео https://youtu.be/u7DRojqcNnE).

9. Предложите свою задачу на графовую базу данных.

10. В качестве ответа прикрепить ссылку на репозиторий Git:
    1) файл "Task.txt"  — условие задачи;
    2) .bak  — резервная копия БД;
    3) .sql  — скрипт пунктов 1–6;
    4) .drawio — диаграммы (каждая на отдельной странице);
    5) .pbix — Power BI с Force-Directed Graph;
    6) папка с картинками для Force-Directed Graph;
    7) "NewTask.txt" — своя задача (пункт 9).
